Research agenda

Security and reliability for LLM agents

I build tools to audit agent memory, measure workflow reliability, enforce delegated capabilities, and analyze model-generated code. This work builds on my research in privacy-preserving distributed systems.

On this page Agent security Privacy Program analysis Doctoral research
01

Agent Security & Reliability

I quantify what information leaks between sessions in shared graph memories and estimate the reliability of multi-step agent pipelines. I also design runtime controls for the capabilities that agents receive when they act on someone else’s behalf.

Topics I work on

  • Cross-session memory leakage
  • Agent workflow reliability
  • Absorbing Markov chains
  • Purpose-bound delegation
  • Runtime capability enforcement

Related work

  • GraphMemShield
  • Markov chain reliability for LLM agents
  • DelegateGuard
02

Privacy-Preserving Computing

I design privacy-preserving systems for sensitive data and measure what protections cost in practice. My work spans differential privacy, anonymization, and secure computation across IoT, fog, and cloud environments.

Topics I work on

  • Differential privacy
  • Data anonymization
  • Trusted execution environments
  • Privacy measurement
  • Cryptographic access control
  • IoT, fog, and cloud computing

Related work

  • PrivacyGuard
  • POP2TIC
  • Pragmatic differential privacy
  • Privacy-preserving architectures review
03

Program Analysis & Software Security

I treat language models as program samplers and study the distribution of their outputs. I also develop taint-based analyses to isolate suspicious behavior in software dependencies.

Topics I work on

  • Distributional program analysis
  • Static and dynamic analysis
  • Model-generated code
  • Taint-based slicing
  • Software supply chain security

Related work

  • Distributional program analysis
  • Code slicing for malicious npm package detection
  • SLM-ArchBench

Doctoral research directions

I am seeking a PhD in trustworthy AI, software engineering, and security and privacy.

  • Extend reliability bounds toward certified behavioral guarantees for multi-step agent pipelines.
  • Establish when a security benchmark score supports a claim about the property it is meant to measure.
  • Develop static analyses that characterize distributions of model-generated programs.
  • Formalize privacy and authority guarantees for purpose-bound delegation.
  • Detect malicious dependencies in machine-generated software using taint analysis.
